Nekomi is an open-source website for watching anime in Ukrainian. It collects
information about titles and connects third-party video players, so viewers can
find a title and watch it with Ukrainian subtitles or voiceover.

## Features
- Search and browse anime titles with descriptions and metadata
- Watch through players with Ukrainian subtitles or voiceover
- User profiles with avatar, cover image and custom watch lists

### Stack
- [React 19](https://react.dev/)
- [Next.js 16](https://nextjs.org/)
- [TailwindCSS 3.4](https://v3.tailwindcss.com/)
- [Typescript](https://typescriptlang.org/)
